# DtabaseComparisonCode

Compares the generated species against an external database, to see how much of the network
has been reported before.

| | |
|---|---|
| `Example_with_KEgg.ipynb` | The comparison, against KEGG |
| `Datasets/HarrisonDataAugust2019_molescules.csv` | The reference set compared against |
| `Datasets/glucose_degradation_output2.txt` | The generated species used for the comparison |
| `matches.xlsx` | What matched |
