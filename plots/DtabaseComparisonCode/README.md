# DtabaseComparisonCode

Compares generated species against an external database, to see how much of the network has
been reported before. The folder name is misspelled as committed.

- `Example_with_KEgg.ipynb` — the comparison, against KEGG
- `Datasets/HarrisonDataAugust2019_molescules.csv` — the reference set
- `Datasets/glucose_degradation_output2.txt` — the generated species used
- `matches.xlsx` — what matched
