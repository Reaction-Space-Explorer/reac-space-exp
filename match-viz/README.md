# match-viz

Interactive view of the structures reported by Yang and Montgomery (1996) that were matched
in the alkaline glucose degradation network, built with
[mols2grid](https://github.com/cbouy/mols2grid).

Served at
[reaction-space-explorer.github.io/reac-space-exp/match-viz](https://reaction-space-explorer.github.io/reac-space-exp/match-viz/).

| | |
|---|---|
| `index.html` | The viewer, self-contained. This is the published page |
| `ym_matches.ipynb` | Builds `index.html` from the matched structures |
| `young_and_mont_matched.csv` | The matched structures, SMILES with names |
| `LICENSE` | MIT, from the repository this came from. The rest of this repository is BSD-3 |

Cited by the Chem. Sci. 2022 ESI, which gives the older address
`reaction-space-explorer.github.io/match-viz/`. That repository has been folded into this one
and the page moved to the address above.
