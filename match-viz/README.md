# match-viz

Structures from Yang and Montgomery (1996) matched in the glucose degradation network, viewed
with [mols2grid](https://github.com/cbouy/mols2grid).
[Live page](https://reaction-space-explorer.github.io/reac-space-exp/match-viz/).

- `index.html` — the viewer, self-contained; this is the published page
- `ym_matches.ipynb` — builds it from the CSV
- `young_and_mont_matched.csv` — the matched structures
- `LICENSE` — MIT, from the repository this came from

Cited by the Chem. Sci. 2022 ESI at its old address, `reaction-space-explorer.github.io/match-viz/`.
