# query_images

Screenshots of matched cycles from the Neo4j browser, kept as a record of what the queries
return and used in talks.

Named for the cycle size they show: `Size3_Pattern Match Rxn and Molecule Labels.JPG` and the
size-4 equivalent show a matched cycle with the reaction and molecule labels visible,
`molecule_ring_size_4.JPG` the same without them. `Cycle diagrams.pptx` collects them.
