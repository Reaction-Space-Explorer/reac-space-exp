# archive

- `_FINAL_QUERY_single_label.TXT`, `_FINAL_QUERY_PARAMETERIZED_single_label_graph.txt` — against a network where molecules and reactions carry one label rather than two
- `Pereto_simple_loop.txt`, `Pereto_simple_loop (2).txt` — the simple loop of Peretó, which regenerates one copy rather than more
- `checkpoint*.txt` — working versions saved while the query was built
- `queries_tested_using_mock_data/` — the versions run against [`../../mock_data`](../../mock_data)
