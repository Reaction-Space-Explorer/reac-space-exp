# output_examples

One complete run of the loader and queries, kept so the output format can be seen without
running anything. The folder is named for when it ran; inside it:

- `autocat_query.txt`, `autocat_query_parameters.csv` — the query and its parameters
- `autocat_query_results.csv`, `.json` — the cycles matched
- `betweenness_centrality.csv`, `.json` — centrality over the network
- `_network_info.csv` — size and shape of the network queried
- `Neo4j_Imports/` — the network itself
