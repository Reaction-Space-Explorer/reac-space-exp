# course_homework

Worked homework for the course whose slides are in [`../lectures`](../lectures), using
[MassPy](https://masspy.readthedocs.io/). **Third-party material**: the questions are the
course's, and the solutions were written by Alejandro Lozano while taking it.

`homework1solutions.ipynb` through `homework7solutions.ipynb`, plus
`homework_2_simulation_simulink.slx` for the Simulink part. `README.md` is the note that came
with them.

These are not analyses of the networks in this repository; the analyses are one level up.
