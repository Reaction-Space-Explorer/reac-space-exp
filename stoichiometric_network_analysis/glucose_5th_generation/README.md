# glucose, fifth generation

The glucose degradation network at generation 5, and how the species found compare against
the reference list.

- `glucose_degradation_output.txt` — the network at this generation
- `Glucose_Degdatation_matches.txt` — species that matched
- `Glucose_Degdatation_missed.txt` — species that did not
- `ModvsRdkit_tautoemrs.ipynb` — compares how MØD and RDKit canonicalise tautomers, where much of that disagreement comes from

The two `.txt` names carry a typo, Degdatation, as committed.
