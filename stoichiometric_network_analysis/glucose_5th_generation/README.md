# glucose, fifth generation

The glucose degradation network at generation 5, and a check of how the species found
compare against the reference list.

| | |
|---|---|
| `glucose_degradation_output.txt` | The network at this generation, species with the generation each appeared in |
| `Glucose_Degdatation_matches.txt` | Species that were matched |
| `Glucose_Degdatation_missed.txt` | Species that were not |
| `ModvsRdkit_tautoemrs.ipynb` | Compares how MØD and RDKit canonicalise tautomers, which is where much of the disagreement in the two lists above comes from |

The two `.txt` filenames carry a typo, Degdatation, as they were written.
