# Stoichiometric network analysis

Stoichiometric analysis of the networks generated in this repository, by
**Alejandro Lozano** ([@alejandro-lozano-dev](https://github.com/alejandro-lozano-dev)).
It rests on linear algebra, graph theory and control theory; the four fundamental subspaces
are the part worth understanding first, and Gilbert Strang's
[18.06 lectures](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/) on column
space, null space and the
[four fundamental subspaces](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-10-the-four-fundamental-subspaces/)
are the clearest treatment.
