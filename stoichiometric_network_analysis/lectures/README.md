# lectures

Course lectures on stoichiometric network analysis, kept with the analyses that use the
method. **Third-party material, not produced by this project**: they are the slides for
*Dynamic States of Biological Networks*, Bernhard Palsson's course, exported from Keynote in
2020, and all rights remain with their author.

Fourteen PDFs, `123.Lecture1` through `123.Lecture14`, covering the basics, simulation, the
red blood cell and glycolysis, coupling pathways, and building networks.

The textbook these follow is published openly by
[MassPy](https://masspy.readthedocs.io/en/latest/notebooks/SB2_textbook/SB2-Chapter-1.html)
as runnable notebooks, which is the better starting point if you only want the method.

Added to this repository by Alejandro Lozano in 2020.
