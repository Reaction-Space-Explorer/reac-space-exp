Scratch scripts kept for reference. Not a test suite, and not part of the pipeline.

- `compare_ms.py` — compares generated species against a mass spectrum
- `generate_input.py`, `input_0.py` — building input files for a run
- `main.py`, `test.py` — small drivers
- `mod/hcn_formal.py` — an HCN network written directly for MØD
- `edge_reactions_manually_noticed.txt` — reactions spotted by hand while checking output
